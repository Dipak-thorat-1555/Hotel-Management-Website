# 🏨 StayAura – Luxury Hotel Website

A modern and elegant hotel website built using HTML, CSS, and JavaScript. StayAura provides a clean and user-friendly interface to explore hotel rooms, view room prices, and check booking availability.

## ✨ Features

- 🏠 Attractive homepage with a luxury hotel theme
- 🛏️ Room listing with descriptions and prices
- 💰 Room prices displayed in Indian Rupees (₹)
- 📅 Check-in and check-out date selection
- 👥 Guest selection
- 📋 Booking availability form
- 🛎️ Individual room booking buttons
- 📞 Contact information section
- 📱 Responsive design (depending on CSS implementation)
- 🎨 Stylish user interface using Google Fonts

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **JavaScript** – Interactive functionality
- **Google Fonts** – Poppins typography

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/Dipak-thorat-1555/Hotel-Management-Website.git
   ```

2. Open the project folder in Visual Studio Code.
3. Make sure all image files are in the correct folder.
4. Open `index.html` in your browser, or run it using the Live Server extension in VS Code.
